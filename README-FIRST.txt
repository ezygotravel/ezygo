EZYGO - SUPABASE MEDIA VERSION

THIS WEBSITE ZIP CONTAINS NO COUNTRY/PACKAGE CARD IMAGES.

1. Upload the CONTENTS of this ZIP to GitHub.
2. Let Cloudflare deploy.
3. In Supabase SQL Editor, run: supabase/starter-content.sql
4. Separately unzip EzyGo-Supabase-Media-Upload.zip on your computer.
5. Open /admin, login with your Admin ID.
6. Open "Starter media".
7. Select the extracted SUPABASE_IMAGE_IMPORT folder.
8. Click "Upload all starter images to Supabase".
9. Keep the admin page open until it reaches 100%.

After that, every visa/package image is stored in Supabase Storage.
Future image changes continue to work through the normal Admin image upload fields.
